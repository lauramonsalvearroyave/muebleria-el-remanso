# El Remanso — Sitio web

Sitio web de Mueblería Artesanal El Remanso: catálogo, historia de la marca y contacto por WhatsApp.

## Estructura

- `index.html` — Inicio (incluye la sección "Nuestra historia")
- `catalogo.html` — Catálogo de productos, con botón "Me interesa"
- `contacto.html` — Contacto, mapa y formulario
- `ayuda-legal.html` — Preguntas frecuentes, términos y política de datos personales
- `assets/` — Estilos, imágenes del logo y scripts

## Cómo verlo localmente

Abre `index.html` directamente en el navegador (doble clic), no necesita servidor.

## Publicación

Este sitio está pensado para publicarse como página estática (GitHub Pages, Netlify, etc.). No requiere proceso de build.
